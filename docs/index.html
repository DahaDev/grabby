Questions

The honest answers.

Is this legal?

Grabby is a tool, like a video player or a web browser. What you do with it is up to you. Downloading content you have the rights to — your own posts, public-domain or Creative Commons material, or content for personal offline viewing in jurisdictions where that's permitted — is fine. Downloading copyrighted content without permission may violate the source platform's terms of service and the copyright law in your country. You're responsible for how you use this tool.

Will I see a security warning on first launch?

On macOS: no. Grabby is signed with an Apple Developer ID and notarized by Apple, so it opens like any other trusted app — no warnings, no right-click-and-Open dance.

On Windows: yes, the first time. Windows SmartScreen will show "Windows protected your PC" because Grabby isn't yet signed with a Windows code-signing certificate. Click More info → Run anyway. After the first launch, Windows trusts the app. We'll add Windows signing in a future release.

What does it cost?

Nothing. Grabby is free and the source code is on GitHub. There are no ads. There's no tracking. There's no in-app purchase. If that changes someday — for example, an optional Pro version with cloud features — it'll be announced clearly and the basic local version will remain free.

Why does YouTube sometimes fail?

YouTube periodically changes its internal APIs to break video downloaders. The community-maintained yt-dlp engine that powers Grabby usually pushes a fix within days. Grabby's auto-updater means you'll get the fix on next launch.

Can I download Snapchat stories?

Only public Snapchat Spotlight videos. Stories and private Snaps are end-to-end-ish and ephemeral by design — no tool can reliably download those. We're not pretending otherwise.

Does it support 4K?

Yes, where the source platform provides it. The default quality selector preferentially picks H.264 codecs for compatibility with QuickTime and Windows Media Player; you can also pick higher-quality VP9 / AV1 streams manually if you have a modern video player like VLC.

What data does Grabby collect?

None. There's no analytics, no telemetry, no crash reporting. The only network traffic the app makes is to (a) the video host you paste a link from, and (b) GitHub's release API for auto-update checks. You can verify this — the source code is public.
